Architecture

Provider details end at category-focused adapter normalizers. Adapters publish unstamped candidates; the runtime validates their strict Core schema, adds runtime identity and sequence, then gives every downstream service the same ordered envelope. Each runtime run has exactly one owning Agent instance.

Layer rule. Surface ground truth and provider-neutral Core contracts are independent foundations. Imposter depends only on Surface; adapters target Core and carry digest-locked ground-truth maps; Runtime has no concrete adapter dependencies. Official adapter composition lives in @vibefield/puppeteer-builtin-providers. See the top-level architecture guide and RFC 004.
Schema boundary. Each Core event category owns strict Zod schemas and exports TypeScript types inferred from them. The exhaustive catalog binds all 43 category:event-name routes to those schemas. Runtime validation uses Zod once at adapter ingress; listener callback narrowing is derived in TypeScript from the same catalog.

Quick start

Create through the runtime; do not construct Agent directly. Spawn failures are returned as data, so narrow the result before subscribing. 

import { createBuiltinAgentRuntime } from '@vibefield/puppeteer-builtin-providers';

const runtime = createBuiltinAgentRuntime({ host, defaultCwd: process.cwd() });

const result = await runtime.spawn({
  agent: 'claude',
  workspace: { mode: 'worktree', path: process.cwd() },
  agentOptions: { model: 'sonnet', permissionMode: 'plan' },
});

if ('error' in result) throw new Error(result.error.message);
const agent = result;

const offTurns = agent.on('turn:*', (envelope) => {
  console.log(envelope.type, agent.state.lifecycle);
});

const offContext = agent.on('context-window:updated', ({ event }) => {
  console.log(`${event.usedTokens}/${event.capacityTokens}`);
});

const offAll = agent.on('*', ({ category, type, sequence }) => {
  console.log(sequence, category, type);
});

const receipt = await agent.submitPrompt({ text: 'Review this repository' });
console.log(agent.lifecycle, agent.alive, agent.status, agent.monitor.usage);

// Persist this as one opaque value; adapter-specific resume state stays private.
const continuation = agent.info.continuation;
const resumed = await runtime.resume({ continuation });

offTurns();
offContext();
offAll();
Subscription timing. Adapter bootstrap events are buffered until the runtime attaches the owning Agent. Application listeners added after spawn() observe subsequent live events; use agent.state and agent.monitor for the already-projected current snapshot.

Subscriptions and typed selectors

Selectors narrow the listener envelope at compile time. All forms receive the same immutable envelope; only their routing breadth differs.

exact

'context-window:updated'

AgentEventEnvelope<ContextWindowUpdatedEvent>

One public route. Best when a consumer owns one concrete behavior.

category

'tool:*'

AgentEnvelopeForCategory<'tool'>

Every route owned by one event category. The nested event remains a discriminated union.

catch-all

'*'

AgentEventEnvelope<AgentEvent>

Every normalized envelope for logging, diagnostics, replay, or generic instrumentation.

type AgentEventSelector =
  | '*'
  | `${AgentEventCategory}:*`
  | AgentEventType;

const unsubscribe = agent.on('tool:completed', ({ event }) => {
  // event is ToolCompletedEvent here
  console.log(event.toolCallId, event.durationMs);
});

unsubscribe();
Delivery contract. Publication is synchronous. The Agent updates its state and feeds monitor evidence before invoking listeners; monitor publication may be coalesced. A listener exception is reported through the runtime error hook and does not stop other listeners or adapter ingestion. Do not depend on relative ordering between listeners registered on different selector scopes. Schema-owned event structures are recursively frozen; opaque tool input/output and retained nativeEvent evidence are not recursively frozen and must be treated as read-only by consumers.

The event envelope

The envelope and normalized payload share one canonical identity: envelope.type === envelope.event.type. Both always follow category:event-name. Raw provider evidence, when retained, stays in nativeEvent and never changes public routing. 

interface AgentEventEnvelope<T extends AgentEvent = AgentEvent> {
  type: AgentEventTypeFor<T>; // public route, e.g. "turn:started"
  category: AgentEventCategoryOf<T>;
  eventId?: string;
  sourceEventRef?: {
    namespace: string;
    eventId: string;
    revisionKey?: string;
    sourceGeneration?: number;
    cursorStart?: number;
    cursorEnd?: number;
  };
  sequence: number;               // monotonic delivery order for this Agent
  sessionId: string;
  nativeSessionId?: string;
  promptId?: string;              // user-turn correlation
  turnId?: string;                // assistant response-cycle correlation
  agentId?: string;               // provider-native actor; absent means root
  agentType?: string;
  actorKey?: string;              // stable derived non-root actor lane
  actorRole?: 'child' | 'auxiliary' | 'unknown';
  providerVersion?: string;
  timestamp: string;              // ISO 8601 wall-clock time
  monotonicTime: number;
  source: AgentEventSource;
  confidence: AgentEventConfidence;
  replay?: boolean;               // durable history, not a new live event
  event: T;                       // normalized provider-neutral payload
  nativeEvent?: unknown;          // retained raw provider evidence
}
Source identity. When an adapter supplies sourceEventRef, the runtime derives a stable delivery identity from its namespace, event id, revision, source generation, and cursor range. An exact source revision is delivered once within the runtime's bounded replay window; changing revision metadata represents a legitimate correction and produces a distinct envelope identity. sequence remains delivery order, not source identity.
route type + category drive fan-out identity ids correlate run, turn, actor, and source evidence source + confidence explain trust escape hatch nativeEvent retains raw evidence

Operational semantics

The invariants consumers can safely design around.

One owner

Each managed spawn, adoption, or restore has one runtime Agent and one adapter subscription.

Normalized boundary

Provider-native names and shapes do not escape as public routes. Strict category schemas validate every candidate; unknown evidence is retained explicitly.

Stable ordering

The runtime restamps monotonically increasing sequence numbers before projection and fan-out.

Idempotent state

The reducer ignores non-increasing sequence numbers and records bounded diagnostics for invalid transitions.

Separate identities

Runtime run, terminal session, native session, prompt, turn, and actor correlations are not collapsed.

Separate facts

Process exit, semantic session exit, turn completion, context pressure, token burn, and account quota are distinct.

Safe listener faults

One observer cannot break ingestion or prevent other observers from receiving the same envelope.

Explicit uncertainty

Evidence carries source/confidence, replay is marked, and prompt submission may return uncertain.
