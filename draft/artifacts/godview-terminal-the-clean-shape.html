1

⌘G. The renderer asks; main owns the one godview bit and flips it. No bit, no deck — no bridge, no socket, no shell.

2

One ticket, once. Main asks fieldd for a connection ticket, forks the bridge, hands the renderer its MessagePorts. That ticket is the EL7 boundary — there is no per-session ticket dance anymore.

3

The workspace meets the floor. It claims whatever already lives there; if the floor is empty it creates its first pane itself — through its own door, spawning platform.defaultShell, which is now your real login shell.

4

Splits are native. New panes ride the workspace's own create doors over the same connection. Nothing is created out-of-band and smuggled in — so there is no race, and no adoption rule to compensate for one.

5

fieldd governs by observation. The G9 session-created event tells it a pane was born; it flips persistence to keep-until-exit and writes the audit record. Policy through seams — not a gate in the create path.

6

The law you can see. Quit the app: the floor keeps every session. The next ⌘G claims them back — the honest ceiling is daemon-lifetime, and the UX says exactly that.

Deleted — the second authority

  • the deck's out-of-band create through terminal.create — the race that minted your sh-3.2$ pane
  • the sessionsToAdopt rule — compensation for births the workspace never saw
  • defaultShell: "/bin/sh" — the hardcode that leaked through the library's own doors
  • ticket-rides-create — needed only because creates happened outside the connection

Unchanged — these were never tricks

  • bridge recovery ladder — transport custody is genuinely the shell's job
  • GT-2c deck laws — transitions are news, updaters are pure, retries mint fresh runtimes
  • GT-2d orphan reaper + nativeBuild provenance — dev hygiene, orthogonal
  • terminal.create as the product API for iOS, agents, tests — one door per client class
