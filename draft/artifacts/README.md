# Live artifact copies

Byte-for-byte copies of every artifact published from Claude Code sessions on this project, saved 2026-09-11 from the live pages rather than from the local drafts under `protos/`. The Updated column is the gallery's own date. Each file is the page exactly as the viewer serves it, wrapped in its doctype and head, so it opens directly in a browser.

Refresh a copy by reading the artifact again with the Artifact tool (`action: read`) and saving the returned HTML over the file. Pages that load Google Fonts or a CDN script need the network for those; everything else is inline. The decision pickers on the proposal pages talk to the claude.ai runtime and do nothing in a local copy.
